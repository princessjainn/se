# Hostel Reallocation System

## Description

Hostel Reallocation System is a simple web-based application that allows students to apply for hostel room reallocation. Students can enter their details, select their current and preferred hostels, and submit a request.

## Technologies Used

* HTML
* CSS


## Features

* Student application form
* Current and preferred hostel selection
* Form validation
* Reallocation request status tracking
* Application and pending request counters
* Responsive user interface

## How to Run

1. Save the code as `index.html`.
2. Open the file in any web browser.
3. Fill in the student details and submit the application.

## Note

This is a frontend prototype. Data is not permanently stored because a backend and database have not been implemented.
